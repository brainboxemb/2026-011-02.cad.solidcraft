A second fixed cross-section of the generic GuideRail component. The aluminium shape comes from the Makita 199141-8 STEP reference and is calibrated to the TSO measured 182.50 × 10.28 mm envelope. The standalone CAD example uses 600 mm for compact visual inspection; Makita's referenced product length is 1500 mm.

Construction stages

  1. Select the fixed Makita cross-section at build time
  2. Create one detailed XZ Polygon2D
  3. Approximate the STEP's small round edges with short line segments
  4. Extrude symmetrically along Y to the 600 mm example length

"""Reusable guide rail with interchangeable fixed cross-sections.

`length` is the only native CAD parameter. `profile` is a non-parametric
component input selecting one fixed measured reference cross-section.
"""
from scpf import Polygon2D, Sketch, component

from models.components.guide_rail.scpf.profiles import get_profile


@component(include=("length",))
class GuideRail:
    length = 600.0
    profile = None

    def build(self):
        profile_data = get_profile(self.profile or "festool")
        points = [
            (f"p{index:03d}", point)
            for index, point in enumerate(profile_data.POINTS)
        ]

        with Sketch(
            name=f"Guide rail profile - {profile_data.PROFILE_NAME}",
            plane="XZ",
        ) as profile_sketch:
            Polygon2D(points, plane="XZ", world=True)

        return profile_sketch.extrude(self.length, sym=True)
