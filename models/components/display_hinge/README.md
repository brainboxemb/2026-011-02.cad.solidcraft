# Display Hinge

Provisional reusable hinge component for the wooden HUB75 display enclosure.

The first implementation is intentionally a conventional external 180-degree
pin hinge:

- two printed PETG leaves;
- five alternating knuckles;
- one removable 4 mm metal pin;
- two mounting holes per leaf;
- default CAD state shown fully open.

The 36 mm hinge length is only a scale reference from the existing HUB75 hinge
ideas page. It is not copied manufacturing geometry.

The earlier hinge research also includes concealed multi-link and spider-hinge
concepts. Those remain valid follow-up directions, but they should build on a
qualified enclosure mounting/pivot interface rather than being approximated in
this first component.

No STL is declared yet because the owner currently contains two printable
leaves plus a separate metal pin. Production outputs should be split per
physical printable part after the fit review.
