SCPF CAD models for SolidCraft

This library contains CAD models built with SCPF for SolidCraft. It ranges from small feature examples to reusable components and complete assemblies. Each model page shows the SCPF code, the generated SolidCraft commands and the resulting geometry, so the repository works as both a CAD library and a practical SCPF reference.
