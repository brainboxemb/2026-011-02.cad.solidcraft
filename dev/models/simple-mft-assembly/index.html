Simple MFT assembly

Reusable Simple MFT worktop with an 800 mm Festool-profile GuideRail

Built in SolidCraft 0.48.1 33 commands

Model preview

The first Simple MFT assembly reuses the exact worktop component and the generic GuideRail component. The rail runs along the short Y/depth direction, is centred over X=0 and rests on the parametrically shared worktop top face.

Key dimensions: 805 × 555 mm worktop; shared worktop thickness 18 mm; Festool GuideRail 800 mm

Model context

Background

Reference basis

The Simple MFT worktop is a photo-based study of the CRAFTMAKER ProStation S30 replacement worktop. The model covers the worktop plate, not the complete workbench.

The front product reference shown below is useful because the complete worktop, the 9 × 7 hole grid and all eight clamp slots are visible at once. The local 2D expectation is kept beside it so the inferred layout can be reviewed without opening SolidCraft.

Known dimensions

Published replacement-top dimensions used by the model are:

  • 805 × 555 × 18 mm;
  • Ø20 mm dog holes.

The front reference supports a 9 × 7 hole grid. The current nominal pitch is 76 mm in X and Y.

Photo-based slot estimate

The front reference was aligned against the known worktop envelope and visible hole grid. These values are estimates, not manufacturer specifications.

Eight slots are visible: two in each quadrant.

Current nominal values:

  • slot width: 24 mm;
  • end-cap centre distance: 80 mm;
  • overall slot length: about 104 mm;
  • slot angle: approximately 45°.

For each quadrant, the inner slot starts at diagonal grid ring 1 (±76, ±76) and extends outward. The outer slot starts at diagonal grid ring 3 (±228, ±228) and extends inward. The four diagonal ring-2 positions (±152, ±152) are intentionally left without dog holes.

The model therefore keeps a complete editable 9 × 7 sketch pattern but cuts only 59 of the 63 circle profiles.

The 76 mm pitch, 20 mm corner cuts and slot dimensions remain photo-derived estimates.

Reuse

The standalone worktop is also a reusable SCPF component. The assembly variant uses the same worktop definition and adds the generic GuideRail component with the Festool profile at 800 mm. The rail is centred over X=0 and rests on the worktop top face.

scpf/assemblies/guide_rail.py
"""Simple MFT worktop with one reusable 800 mm guide rail.

World axes:
    X: left/right across the worktop width
    Y: front/rear along the worktop depth and guide-rail length
    Z: up

The rail is deliberately placed by this assembly. GuideRail owns only its local
profile and length; SimpleMFT owns only the worktop geometry.
"""
from scpf import Placement, half

from models.advanced.simple_mft.scpf.model import SimpleMFT
from models.components.guide_rail.scpf.model import GuideRail
from models.components.guide_rail.scpf.profiles import get_profile


class SimpleMFTAssembly:
    # Shared parent parameter: changing this moves the worktop top face and the
    # rail together instead of leaving the rail at a hard-coded Z=18 position.
    worktop_thickness = SimpleMFT.thickness

    # Compact assembly example. Keep the length editable in the assembly.
    guide_rail_length = 800.0

    GUIDE_RAIL_PROFILE = "festool"

    def build(self):
        profile = get_profile(self.GUIDE_RAIL_PROFILE)

        worktop = SimpleMFT(
            thickness=self.worktop_thickness,
        )

        # GuideRail's fixed profile starts at local X=0 and extends to +WIDTH,
        # while its length is already symmetric about local Y=0. Shifting it by
        # half its width centres the rail over worktop X=0 without a rotation.
        #
        # Z uses the same parent parameter passed into SimpleMFT.thickness, so
        # the rail remains on the top face when worktop_thickness is edited in
        # the saved SolidCraft model.
        guide_rail = GuideRail(
            length=self.guide_rail_length,
            profile=self.GUIDE_RAIL_PROFILE,
            placement=Placement(
                x=-half(profile.WIDTH),
                z=self.worktop_thickness,
            ),
        )

        return worktop + guide_rail
