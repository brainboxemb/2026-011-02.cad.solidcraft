FlexBenchDog

Passive 20 mm MFT bench dog with a four-segment flex stem

Built in SolidCraft 0.49.0 56 commands

Model preview

A printable bench dog inferred from the Mini-MFT reference image: 20 mm above and 20 mm below the worktop, with one full-length tapered insert from Ø20.0 at the worktop to Ø20.2 at the free end. A compact Ø22 stop collar seats on the 45° chamfer of a nominal Ø20 MFT hole. Two perpendicular slots create four flexible legs, with R0.5 mm relief around the central cross. The top face carries a recessed BrainBox cube/box wireframe.

Key dimensions: 20.0 mm nominal hole; Ø22 × 1.5 mm stop collar; 1.5 mm flex slots; Ø20.0 → Ø20.2 taper

Construction stages

  • Cylinder — create Ø22 × 1.5 mm stop-collar envelope at worktop datum
  • Chamfer — 1.0 mm lower outer collar edge back to Ø20 at 45°
  • Cylinder — join Ø20 × 18.5 mm working section to Z=20
  • Cone — join one 20 mm insertion taper from Ø20.2 free end to Ø20.0 worktop end
  • Two 1.5 × 16 mm crossing cuts create four flex legs
  • Fillet — R0.5 mm on the four vertical inner corners around the central cross
  • Chamfer top and bottom edges
  • Sketch/cut — recess nine 0.6 mm BrainBox cube-wireframe strokes on the top face

"""Reusable 20 mm flex bench dog based on the supplied Mini-MFT reference image.

The CAD orientation is functional rather than a prescribed print orientation:
the worktop surface is Z=0, the insert extends 20 mm downward and the dog rises
20 mm upward. The insert tapers continuously from Ø20.0 at the worktop to
Ø20.2 at the free end, providing passive spring preload after the stem is split
into four flexible quadrants.
"""

from scpf import (
    Anchor,
    Cone,
    Cylinder,
    Rectangle2D,
    Sketch,
    SlotCenterToCenter2D,
    component,
)


@component
class FlexBenchDog:
    hole_diameter = 20.0
    interference = 0.20
    rim_diameter = 22.0
    slot_width = 1.5
    slot_corner_radius = 0.5

    ABOVE_WORKTOP = 20.0
    RIM_THICKNESS = 1.5
    RIM_SEAT_CHAMFER = 1.0
    INSERTION_LENGTH = 20.0
    SLOT_LENGTH = 16.0
    TOP_CHAMFER = 0.6
    BOTTOM_CHAMFER = 1.0
    LOGO_LINE_WIDTH = 0.6
    LOGO_DEPTH = 0.6

    LOGO_SEGMENTS = (
        ((0.0, 4.0), (3.5, 2.0)),
        ((3.5, 2.0), (3.5, -2.0)),
        ((3.5, -2.0), (0.0, -4.0)),
        ((0.0, -4.0), (-3.5, -2.0)),
        ((-3.5, -2.0), (-3.5, 2.0)),
        ((-3.5, 2.0), (0.0, 4.0)),
        ((0.0, 0.0), (0.0, 4.0)),
        ((0.0, 0.0), (3.5, -2.0)),
        ((0.0, 0.0), (-3.5, -2.0)),
    )

    def build(self):
        # The stop collar sits on the small 45-degree mouth chamfer of a
        # nominal 20 mm MFT hole. Its Ø22 × 1.5 mm envelope is chamfered only
        # at the lower outside edge: 1 mm radial difference gives a 1 mm axial
        # 45-degree seat, leaving a 0.5 mm straight Ø22 land above it.
        rim = Cylinder(
            d=self.rim_diameter,
            h=self.RIM_THICKNESS,
            anchor=Anchor.BOTTOM,
        )
        rim = rim.chamfer(
            self.RIM_SEAT_CHAMFER,
            edges=[(self.rim_diameter / 2, 0, 0)],
        )

        working_height = self.ABOVE_WORKTOP - self.RIM_THICKNESS
        upper = Cylinder(
            d=self.hole_diameter,
            h=working_height,
            anchor=Anchor.BOTTOM,
        ).at(0, 0, self.RIM_THICKNESS, anchor=Anchor.BOTTOM)
        dog = rim + upper

        # Full-length insertion taper: Ø20.2 at the free end (Z=-20) to
        # nominal Ø20.0 at the worktop datum (Z=0). Forge #746 provides the
        # native joined-Cone path; no stepped cylindrical tip remains.
        insert = Cone(
            d=self.hole_diameter + self.interference,
            top_d=self.hole_diameter,
            h=self.INSERTION_LENGTH,
            anchor=Anchor.BOTTOM,
        ).at(0, 0, -self.INSERTION_LENGTH, anchor=Anchor.BOTTOM)
        dog = dog + insert

        # Give the complete free insert edge a larger lead-in before splitting
        # it into four flexible legs.
        dog = dog.chamfer(
            self.BOTTOM_CHAMFER,
            edges=[(
                (self.hole_diameter + self.interference) / 2,
                0,
                -self.INSERTION_LENGTH,
            )],
        )

        # Two native sketch cuts form the cross slots. They start at the free
        # end and stop 4 mm below the worktop, leaving a solid flex root.
        slot_span = self.hole_diameter + self.interference + 2.0

        with Sketch(
            name="Flex slot X",
            on=dog,
            plane="XY",
            origin=(0, 0, -self.INSERTION_LENGTH),
        ) as slot_x:
            Rectangle2D(slot_span, self.slot_width)
        dog = dog - slot_x.extrude(self.SLOT_LENGTH)

        with Sketch(
            name="Flex slot Y",
            on=dog,
            plane="XY",
            origin=(0, 0, -self.INSERTION_LENGTH),
        ) as slot_y:
            Rectangle2D(self.slot_width, slot_span)
        dog = dog - slot_y.extrude(self.SLOT_LENGTH)

        # Round only the four vertical material corners around the central
        # cross. The rectangular slot dimensions and 4 mm solid root remain
        # unchanged.
        slot_half = self.slot_width / 2
        slot_edge_z = -self.INSERTION_LENGTH + self.SLOT_LENGTH / 2
        dog = dog.fillet(
            self.slot_corner_radius,
            edges=[
                (slot_half, slot_half, slot_edge_z),
                (-slot_half, slot_half, slot_edge_z),
                (-slot_half, -slot_half, slot_edge_z),
                (slot_half, -slot_half, slot_edge_z),
            ],
        )

        # Light chamfer on the visible upper perimeter.
        dog = dog.chamfer(
            self.TOP_CHAMFER,
            edges=[(self.hole_diameter / 2, 0, self.ABOVE_WORKTOP)],
        )

        # Recess the BrainBox wireframe as nine independent rib cuts. PR #341
        # put all nine overlapping closed Slot profiles in one Sketch, which
        # created extra enclosed regions and visually removed a filled face.
        # Keeping one Slot profile per Sketch preserves the same nine visible
        # cube edges without allowing intersections to create face regions.
        #
        # TEMPORARY compatibility workaround — CAD #348 / Forge #747.
        # The preferred final construction is one closed polygon strip per rib.
        # Remove this one-Slot-per-Sketch workaround only after Forge #747
        # reaches a released version consumed by this repository.
        for index, (p0, p1) in enumerate(self.LOGO_SEGMENTS, start=1):
            with Sketch(
                name=f"Top logo rib {index}",
                on=dog,
                plane="XY",
                origin=(0, 0, self.ABOVE_WORKTOP),
            ) as rib:
                SlotCenterToCenter2D(p0, p1, self.LOGO_LINE_WIDTH)
            dog = dog - rib.extrude(-self.LOGO_DEPTH)

        return dog
