## Design/reference source

This Wall Hook reconstruction uses the following YouTube tutorial as its
design/reference source. Confirmed dimensions in the model remain distinguished
from the small profile/window radii that were inferred from the rendered
tutorial result.

## Lower mounting screw access

The lower Ø4.2 mm mounting hole still passes only through the 6 mm rear mounting
spine. A separate Ø10 mm opening is cut through the diagonal reinforcement on
the same X axis, providing a straight screwdriver/bit path without turning the
reinforcement itself into part of the mounting hole.

The access diameter is an explicit model parameter so it can be revised if a
different driver clearance is required.
