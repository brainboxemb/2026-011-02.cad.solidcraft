Benchdog Clamp (WIP)

Source-derived MFT rail clamp concept with low hinge and Ø20 bench-dog reference

Built in SolidCraft 0.49.0 50 commands

Model preview

Work-in-progress reconstruction of the final visible state in the supplied doghole_clamp2 SolidCraft design. The active baseline keeps the low T-slide with fixed centre hinge eye, mirrored side arms, Ø3 hinge pin, 40 mm dummy rail-profile fit context and a straight Ø20 bench-dog reference. Earlier expansion-dog and compact-fork concepts remain in the retained source but are deliberately not part of this active Forge baseline.

Key dimensions: rail 12 / 7 mm with 0.3 mm clearance; Ø3 hinge pin; R3 hinge eye; 0.25 mm axial clearance; 12.55 / 8.30 mm source profile; 40 mm rail context; Ø20 dog at 19.5 mm

Construction stages

  • T-slide — reconstruct native features 63-66 plus late right-side thickening feature 80
  • Hinge arms — use one source arm definition twice at Y = -6 / +6
  • Pin — retain the native Ø3 × 16.5 mm low hinge pin and Ø5 head
  • Rail context — rebuild the 20-point XZ profile and symmetric 40 mm extrusion
  • Rail fillets — reproduce source R1.6 slot-lip and R0.9 lower profile rounds
  • Bench dog — retain the straight Ø20 × 27.5 mm reference; source head remains suppressed
  • Final datum — apply the common source feature-83 Z shift to all visible bodies

Model context

Background

WIP

This is a source-derived working baseline, not a finished clamp design. It intentionally follows the final visible state of the supplied native SolidCraft document before any further design decisions are made.

The retained source contains several earlier clamp and expanding-dog concepts. Those historical bodies are useful design evidence, but the current Forge model only reconstructs the bodies that remain visible at the end of the source timeline.

The first review target is therefore source parity, not optimisation: rail fit, hinge stack, bench-dog position and the final common datum move.

"""WIP Benchdog Clamp reconstructed from the supplied SolidCraft source.

This model intentionally follows only the final visible source state. Earlier
dog-expansion and compact-fork concepts remain in the retained native source,
but are hidden/replaced there and are not part of this first Forge baseline.

World axes match the native document:
    X: across the rail profile
    Y: along the rail / hinge pin
    Z: up

The native document finishes with one common +Z move (feature 83). The reusable
parts below keep their pre-move source coordinates and the assembly applies the
same final placement once per occurrence.
"""

from scpf import (
    Anchor,
    Axis,
    Box,
    Cylinder,
    Edges,
    Placement,
    Polygon2D,
    Sketch,
    component,
)


def _box_from_corner(length, width, height, x, y, z):
    return Box(
        length,
        width,
        height,
        anchor=Anchor.BOTTOM,
    ).at(
        x + length / 2,
        y + width / 2,
        z,
        anchor=Anchor.BOTTOM,
    )


@component(include="*")
class BenchdogClampSlide:
    """Final visible T-slide with fixed centre hinge eye (source 63-66, 71, 80)."""

    rail_inside_width = 12.0
    rail_opening = 7.0
    rail_clearance = 0.3
    rail_top = 6.0
    pin_diameter = 3.0
    hinge_height = 3.5
    hinge_outer_radius = 3.0
    hinge_axial_clearance = 0.25
    hinge_left_shift = 3.0

    def build(self):
        foot_x = -self.rail_inside_width / 2 + self.rail_clearance + 2.0
        foot_z = self.rail_top - 8.4 + self.rail_clearance
        foot_height = (
            self.rail_top - 2.0 - self.rail_clearance
            - foot_z
        )
        slide = _box_from_corner(
            self.rail_inside_width - 2 * self.rail_clearance,
            16.0,
            foot_height,
            foot_x,
            -8.0,
            foot_z,
        )

        neck_x = -self.rail_opening / 2 + self.rail_clearance + 2.0
        neck_z = self.rail_top - 2.0 - self.rail_clearance
        eye_base_z = (
            self.rail_top
            + self.hinge_height
            - self.hinge_outer_radius
            - self.rail_clearance
        )
        slide = slide + _box_from_corner(
            self.rail_opening - 2 * self.rail_clearance,
            16.0,
            eye_base_z - neck_z,
            neck_x,
            -8.0,
            neck_z,
        )

        eye_x = -self.hinge_left_shift + 2.0
        eye_width = -2 * self.hinge_axial_clearance + 8.0
        slide = slide + _box_from_corner(
            4.0,
            eye_width,
            self.rail_top + self.hinge_height - eye_base_z,
            -self.hinge_left_shift,
            -4.0 + self.hinge_axial_clearance,
            eye_base_z,
        )
        slide = slide + Cylinder(
            d=2 * self.hinge_outer_radius,
            h=eye_width,
            axis=Axis.Y,
            anchor=Anchor.FRONT,
        ).at(
            eye_x,
            -4.0 + self.hinge_axial_clearance,
            self.rail_top + self.hinge_height,
            anchor=Anchor.FRONT,
        )

        # Late source feature 80 thickens the right side of the fixed eye.
        thick_x = -self.hinge_left_shift + 3.75
        slide = slide + _box_from_corner(
            -thick_x + 6.5,
            eye_width,
            (
                self.rail_top + self.hinge_height + 2.0
                - eye_base_z
            ),
            thick_x,
            -4.0 + self.hinge_axial_clearance,
            eye_base_z,
        )

        pin_hole = Cylinder(
            d=self.pin_diameter + 0.2,
            h=20.0,
            axis=Axis.Y,
            anchor=Anchor.FRONT,
        ).at(
            eye_x,
            -10.0,
            self.rail_top + self.hinge_height,
            anchor=Anchor.FRONT,
        )
        return slide - pin_hole


@component(include="*")
class BenchdogClampHingeArm:
    """One source hinge arm; the assembly places a mirrored pair at ±Y."""

    rail_top = 6.0
    pin_diameter = 3.0
    hinge_height = 3.5
    hinge_outer_radius = 3.0
    hinge_left_shift = 3.0

    def build(self):
        eye_x = -self.hinge_left_shift + 2.0
        arm = _box_from_corner(
            11.0,
            4.0,
            3.0,
            -self.hinge_left_shift - 9.0,
            -2.0,
            self.rail_top + self.hinge_height - 1.5,
        )
        arm = arm + Cylinder(
            d=2 * self.hinge_outer_radius,
            h=4.0,
            axis=Axis.Y,
        ).at(
            eye_x,
            0.0,
            self.rail_top + self.hinge_height,
        )
        pin_hole = Cylinder(
            d=self.pin_diameter + 0.2,
            h=20.0,
            axis=Axis.Y,
        ).at(
            eye_x,
            0.0,
            self.rail_top + self.hinge_height,
        )
        return arm - pin_hole


@component(include="*")
class BenchdogClampHingePin:
    """Low Ø3 hinge pin with a Ø5 × 1.5 mm head (source 73-74)."""

    rail_top = 6.0
    pin_diameter = 3.0
    hinge_height = 3.5
    hinge_left_shift = 3.0

    def build(self):
        x = -self.hinge_left_shift + 2.0
        z = self.rail_top + self.hinge_height
        pin = Cylinder(
            d=self.pin_diameter,
            h=16.5,
            axis=Axis.Y,
            anchor=Anchor.FRONT,
        ).at(x, -8.0, z, anchor=Anchor.FRONT)
        head = Cylinder(
            d=5.0,
            h=1.5,
            axis=Axis.Y,
            anchor=Anchor.FRONT,
        ).at(x, -9.5, z, anchor=Anchor.FRONT)
        return pin + head


@component(include="*")
class BenchdogClampRailContext:
    """40 mm native dummy rail profile retained as WIP fit context."""

    rail_top = 6.0
    profile_inside_width = 12.55
    profile_opening = 8.30
    profile_length = 40.0

    SLOT_LIP_RADIUS = 1.6
    LOWER_RADIUS = 0.9

    def build(self):
        half_inside = self.profile_inside_width / 2
        half_opening = self.profile_opening / 2

        # These are world (X, Z) points reconstructed from native Sketch 76.
        # Polygon2D(world=True) handles SolidCraft's native XZ sketch-Y sign.
        points = [
            ("l1", (-half_inside + 0.2, self.rail_top)),
            ("l2", (-half_opening + 2.0, self.rail_top)),
            ("l3", (-half_opening + 2.0, self.rail_top - 2.0)),
            ("l4", (-half_inside + 2.0, self.rail_top - 2.0)),
            ("l5", (-half_inside + 2.0, self.rail_top - 8.4)),
            ("l6", (2.0 + half_inside, self.rail_top - 8.4)),
            ("l7", (2.0 + half_inside, self.rail_top - 2.0)),
            ("l8", (2.0 + half_opening, self.rail_top - 2.0)),
            ("l9", (2.0 + half_opening, self.rail_top)),
            ("l10", (2.0 + half_inside + 1.8, self.rail_top)),
            ("l11", (2.0 + half_inside + 1.8, self.rail_top - 6.8)),
            ("l12", (17.1, self.rail_top - 6.8)),
            ("l13", (17.1, self.rail_top - 7.6)),
            ("l14", (29.0, self.rail_top - 7.6)),
            ("l15", (29.0, self.rail_top - 6.8)),
            ("l16", (39.5, self.rail_top - 6.8)),
            ("l17", (39.5, self.rail_top - 9.4)),
            ("l18", (2.0 + half_inside + 1.8, self.rail_top - 9.4)),
            ("l19", (2.0 + half_inside + 1.8, self.rail_top - 10.4)),
            ("l20", (-half_inside + 0.2, self.rail_top - 10.4)),
        ]

        with Sketch(name="Dummy rail profile", plane="XZ") as sketch:
            Polygon2D(points, plane="XZ", world=True)

        rail = sketch.extrude(self.profile_length, sym=True)

        # Native source features 78/79 round the extrusion-axis edges at
        # source curve junctions l1/l20, l10/l9 and l19/l20.
        rail = rail.fillet(
            self.SLOT_LIP_RADIUS,
            edges=Edges.from_vertices("l1", "l10"),
        )
        rail = rail.fillet(
            self.LOWER_RADIUS,
            edges=Edges.from_vertices("l20"),
        )
        return rail


@component(include="*")
class BenchdogClampDog:
    """Straight Ø20 bench dog reference; source head feature 82 is suppressed."""

    rail_top = 6.0
    profile_inside_width = 12.55
    doghole_diameter = 20.0
    benchdog_rail_clearance = 0.5
    benchdog_along_position = 19.5

    DOG_HEIGHT = 27.5

    def build(self):
        x = (
            -self.profile_inside_width / 2
            - self.benchdog_rail_clearance
            - self.doghole_diameter / 2
            + 0.2
        )
        return Cylinder(
            d=self.doghole_diameter,
            h=self.DOG_HEIGHT,
            anchor=Anchor.BOTTOM,
        ).at(
            x,
            self.benchdog_along_position,
            self.rail_top - 10.4,
            anchor=Anchor.BOTTOM,
        )


class BenchdogClamp:
    """Current visible WIP state of the source doghole-clamp design."""

    rail_inside_width = 12.0
    rail_opening = 7.0
    rail_top = 6.0
    rail_clearance = 0.3

    pin_diameter = 3.0
    hinge_height = 3.5
    hinge_outer_radius = 3.0
    hinge_axial_clearance = 0.25
    hinge_left_shift = 3.0

    profile_inside_width = 12.55
    profile_opening = 8.30
    profile_length = 40.0

    doghole_diameter = 20.0
    benchdog_rail_clearance = 0.5
    benchdog_along_position = 19.5

    def build(self):
        # Native source feature 83 moves all final visible bodies together so
        # the reference rail datum lands at its intended final Z position.
        final_z_shift = -self.rail_top + 10.4

        slide = BenchdogClampSlide(
            rail_inside_width=self.rail_inside_width,
            rail_opening=self.rail_opening,
            rail_clearance=self.rail_clearance,
            rail_top=self.rail_top,
            pin_diameter=self.pin_diameter,
            hinge_height=self.hinge_height,
            hinge_outer_radius=self.hinge_outer_radius,
            hinge_axial_clearance=self.hinge_axial_clearance,
            hinge_left_shift=self.hinge_left_shift,
            placement=Placement(z=final_z_shift),
        )

        left_arm = BenchdogClampHingeArm(
            rail_top=self.rail_top,
            pin_diameter=self.pin_diameter,
            hinge_height=self.hinge_height,
            hinge_outer_radius=self.hinge_outer_radius,
            hinge_left_shift=self.hinge_left_shift,
            placement=Placement(y=-6.0, z=final_z_shift),
        )
        right_arm = left_arm.copy(
            placement=Placement(y=6.0, z=final_z_shift),
        )

        hinge_pin = BenchdogClampHingePin(
            rail_top=self.rail_top,
            pin_diameter=self.pin_diameter,
            hinge_height=self.hinge_height,
            hinge_left_shift=self.hinge_left_shift,
            placement=Placement(z=final_z_shift),
        )

        rail = BenchdogClampRailContext(
            rail_top=self.rail_top,
            profile_inside_width=self.profile_inside_width,
            profile_opening=self.profile_opening,
            profile_length=self.profile_length,
            placement=Placement(z=final_z_shift),
        )

        dog = BenchdogClampDog(
            rail_top=self.rail_top,
            profile_inside_width=self.profile_inside_width,
            doghole_diameter=self.doghole_diameter,
            benchdog_rail_clearance=self.benchdog_rail_clearance,
            benchdog_along_position=self.benchdog_along_position,
            placement=Placement(z=final_z_shift),
        )

        return slide + left_arm + right_arm + hinge_pin + rail + dog
