SamplePlate

Three named sketches, a native two-hole pattern and a raised boss

Model preview

Builds a centered plate with native Base, Holes and Bore sketches. One parameter-driven Ø8 hole cut is repeated by a native rectangular pattern, while a Ø24 boss is joined between the two cuts.

Key dimensions: 80 × 50 × 8 mm; R6; Ø24 × 14 boss

Construction stages

  • Sketch and extrude the centered base
  • Fillet the four vertical corners R6
  • Cut one Ø8 source hole
  • Repeat it as a native two-hole rectangular pattern
  • Join the Ø24 boss
  • Cut the central Ø12 bore
  • Publish a native ISO A4 technical drawing as SamplePlate.pdf

@component
class SamplePlate:
    """Build the sample plate from object-level CAD intent."""

    width = 80
    depth = 50
    thickness = 8

    def build(self):
        with Sketch(name="Base", plane="XY") as sketch:
            Rectangle2D(self.width, self.depth)
        plate = sketch.extrude(self.thickness)
        plate = plate.fillet(6, edges=Edges.VERTICAL)

        # One source cut, then a real native SolidCraft rectangular pattern.
        # The first hole and the pitch both keep their width relationship.
        with Sketch(name="Holes", on=plate, parent=Anchor.TOP) as holes:
            holes.add(
                Circle2D(d=8),
                offset=(-half(self.width - 24), 0),
            )
        source_cut = holes.extrude(Depth.THROUGH_ALL)
        plate = plate - source_cut
        plate = plate.rectangular_pattern(
            source_cut,
            count=2,
            spacing=self.width - 24,
            direction=Axis.X,
        )

        boss = Cylinder(d=24, h=14).attach(
            plate,
            parent=Anchor.TOP,
            child=Anchor.BOTTOM,
        )
        plate = plate + boss

        bore = Hole(d=12, depth=Depth.THROUGH_ALL).attach(
            plate,
            parent=Anchor.TOP,
        )
        return plate + bore


def sample_plate():
    """Final SamplePlate design with one native A4 technical drawing."""
    return SamplePlate().with_drawing(name="SamplePlate")
