## Source of truth

The original native SolidCraft file is committed unchanged as
`reference/latch.sc`. A readable `reference/latch.json` export is stored
beside it to make the native parameter and feature history easier to inspect.

This is a generic latch component. Its placement under **Display** is catalog
classification only; the model itself must not be named or coupled as a
display-specific latch.

The reconstruction intentionally follows the source sheet-metal history. Do not
replace folds, flanges, sheet contours or revolved rivets with fused-solid
lookalikes merely to make the model build.
